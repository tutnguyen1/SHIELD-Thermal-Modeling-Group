Uploading Code
- Still figuring this one out... but here's what I did to get it to work the first time
- COMMIT all sandbox changes to local repo. No problems here. Just make sure to put detailed change comments.
- to PUSH local repo to online repo, need to input your Github credentials into Matlab
-   Username is Github username
-   Token is generated in Github (click on the link in Matlab). Its like a one-time password thingy. I checked all access boxes (don't think you need all of them but whatever) and then generated key and then pasted into Matlab to PUSH local to online. If didn't work, token probably wrong/wrong permissions so need to go into Matlab settings to re-set the token (manage credentials). https://www.mathworks.com/help/releases/R2026b/matlab/matlab_prog/set-up-git-source-control.html#mw_779634a2-7613-4f1d-9ef0-e791c35ca19b
